# Tracked Evaluation Outputs

This directory stores reproducible, text-based HorseRacingAI evaluation artifacts in GitHub.

Commit here:

- baseline metric summaries
- 1y / 3y / 5y comparison summaries
- experiment decision logs
- immutable PRE prediction summaries
- final validation / ROI summaries

Do not commit:

- JRA-VAN raw databases
- personally licensed raw data dumps
- large serialized model binaries

Raw/local licensed data remains on the development PC. GitHub keeps the configuration, code and summarized evidence required to reproduce decisions.
